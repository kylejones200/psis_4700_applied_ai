Design matters. Not only accuracy, but clarity. Because users must understand what the system is doing without effort. If the system is confusing, it will not be used. If it overwhelms, it will be ignored.

So you reduce cognitive load. You show what matters and hide what does not. You make the system explain itself at the right level. This connects directly to trust. People trust what they understand, and they reject what they do not. So UX is not decoration. It is part of the system. Now we bring it all together.
