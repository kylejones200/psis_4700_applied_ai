Up to this point, you have seen AI as systems. Now we simplify that view: think in parts, not one large system—small pieces, each doing one job. And this changes how you build. Instead of starting from scratch, you assemble. A model handles reasoning, retrieval provides context, an interface connects to users, memory tracks state, and orchestration connects everything. Each piece is replaceable and each piece can improve over time.

This matters because it changes speed. You do not wait to build everything; you reuse, you combine, you adapt, and that allows you to move faster with less risk. Now this also changes how you think about design. You do not ask what model solves the problem; you ask what combination of pieces solves it, because most real systems are not one capability—they are many, working together.

Step back and the pattern is familiar: multi-model systems, agents, retrieval—all of it points to the same idea, composition. And once you see that, you stop thinking in terms of tools and start thinking in terms of systems you assemble. Now we turn to how you actually use these systems.
