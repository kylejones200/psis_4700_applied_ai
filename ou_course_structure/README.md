## File Types

### Markdown (.md) Files
- Course overview and structure
- Complete module content with lessons
- Instructor and student orientation
- Accreditation and maintenance documentation
- Content mapping templates

### CSV Files
- **Rubrics**: Point-based grading rubrics for each assignment
- **Alignment Tables**: Mapping between course outcomes, module objectives, and assessments

## How to Use

### For Instructional Designers

1. Start with `00_course_overview.md` for course-level information
2. Review module files in `modules/` for lesson content
3. Use content maps in `content_maps/` to map existing materials (PDFs, WebSlides, worksheets) to lessons
4. Use CSV rubrics in `assessments/` for LMS rubric setup
5. Reference alignment tables in `admin/` for outcome mapping
6. Use `templates/` to create Google Docs for content mapping

### For Instructors

1. Read `admin/instructor-orientation-note.md` first
2. Review rubrics in `assessments/` before grading
3. Reference alignment tables to understand assessment purpose

### For Course Maintenance

1. Follow guidelines in `admin/course-maintenance-guide.md`
2. Do not modify learning outcomes or rubrics without approval
3. Use templates in `templates/` when mapping new content

## Next Steps

3. Import CSV rubrics into LMS

## Key Principles

- **Outcomes drive everything**: All content and assessments map to course learning outcomes
- **Stand-alone content**: Every lesson works independently without live instruction
- **Stable structure**: Learning outcomes, objectives, and rubrics remain unchanged
- **Flexible content**: Examples and tools can be updated while preserving structure
